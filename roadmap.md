# Planned Additions

A quick look at upcoming features and ideas under active development for The Collection Curator.

---

## Near Term
* **Desktop Companion Integration:** Support for managing databases on larger screens via Windows & Linux.
* **Enhanced CSV Exporting:** Include optional image file path mapping in backup summaries.

---

## Future Ideas
* **In-App Direct Feedback:** Dedicated in-app option to submit feature requests directly.
* **Bulk Editing Tools:** Ability to re-assign locations or tags to multiple items simultaneously.
